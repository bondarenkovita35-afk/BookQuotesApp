## Om projektet

BookQuotesApp är en CRUD-applikation där inloggade användare hanterar sina egna böcker och sina egna citat. Varje ny användare får fem startcitat automatiskt vid registrering.

## Teknik

- **Frontend:** Angular 20, TypeScript, Bootstrap 5, Font Awesome
- **Backend:** .NET 9, ASP.NET Core Web API, Entity Framework Core
- **Autentisering:** JWT (Bearer-token)
- **Databas:** SQL Server (lokalt via LocalDB, produktion via Azure SQL)
